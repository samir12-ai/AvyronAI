5. Why the original gap mattered (the failure mode without rev 3)
Without the policy files:

server/boss/run.ts line 31-32 (import { evaluateQ1 } from "./policy/dna-working"; import { evaluateQ2 } from "./policy/market-shift";) — TypeScript compile error TS2307: Cannot find module './policy/dna-working'. Boss runs cannot execute. Q1 and Q2 verdicts cannot be computed.
server/pipeline/ai-overlay/q2-reasoning.ts line 40 + assemble.ts line 35 — TS2307 on Q2EvaluationResult type import. AI overlay assembly fails to compile, blocking every /api/pipeline/* route that produces an explanation.
server/pipeline/real-scenario-harness.ts line 36 — TS2307 on decideQ2 and three Q2 context types. Production-shape harness cannot run, blocking the standard pre-deploy verification step.
Without §2.7.1:

Dashboard returns 404 from Main even after routes.ts is mounted. Sam (or any Main admin) cannot view rejection logs, run telemetry, or any dashboard panel — even though the JSON /api/pipeline/* endpoints work.
Both failure modes are now eliminated by rev 3.
