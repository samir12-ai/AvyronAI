3.3 Database safety rules
Do not change the type of any existing primary-key column in Main.
These 12 tables use varchar("id").primaryKey().default(sql\gen_random_uuid()`)— Postgrespgcrypto` extension is required (verified in §0.1.7).
After pasting, run npm run db:push (NOT db:push --force). The 12 new tables are additive — db:push should detect them as new tables only and create them safely. Only escalate to --force if Drizzle reports a non-destructive change you've reviewed.
