## Intended system structure

There are two agent-side pipelines:

1. Competitor Pipeline
2. User Pipeline

They are not the same, and they should not overwrite each other’s data or snapshots.

---

## 1) Competitor Pipeline — intended responsibility

The competitor pipeline should:

- scrape competitor data weekly
- detect whether there is a real market shift
- only treat it as meaningful if more than one competitor shows the same direction
- use Instagram mainly as strategy source
- use TikTok mainly as validation source
- surface weak / insufficient data instead of pretending the market is stable

Important question:

When the competitor pipeline pulls new competitor data, does it analyze that data through Market Intelligence in the backend without corrupting or overwriting the user’s existing Market Intelligence snapshots?

Please audit this specifically.

If the answer is no, we need to fix it.

The competitor pipeline must be able to analyze new competitor data separately, then trigger a new analysis when needed, without mutating the old user snapshot silently.

---

## 2) Competitor shift behavior

If the competitor pipeline detects a market shift, the system should:

- create a clear shift signal
- show an alert on the dashboard
- tell the user/operator that the market changed
- recommend running a new analysis on the new data
- make sure the new analysis uses fresh data, not stale data

Please audit:

- where the shift is detected
- where the signal is stored
- whether the dashboard alert exists
- whether the alert clearly says the next analysis should use new data
- whether stale data can accidentally be reused

---

## 3) User Pipeline — intended responsibility

The user pipeline should:

- scrape the user’s own pages every 48 hours
- check if the user is following the planned rhythm
- check if the published content is working
- separate:
  - Instagram as source/strategy signal
  - TikTok as validation signal
- track paid / organic context where possible
- trigger clarification when paid/organic is uncertain
- help determine whether the current DNA is working

Please audit:

- whether the 48-hour scraping cycle exists
- whether rhythm compliance is actually checked
- whether Instagram and TikTok are treated differently
- whether TikTok validation is used correctly
- whether paid / organic classification is wired or only exists as helper logic
- whether missing weekly truth blocks or downgrades the decision correctly
