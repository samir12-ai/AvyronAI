## Scenario A — Weak / Low-Signal Campaign

- little or weak source data exists

- system must NOT behave aggressively

## Scenario B — Contradictory Campaign

Create a state where:

- some engines suggest strength

- or signal composition is mixed

Expected behavior:

- contradictions must be surfaced

- budget / plan / tasks must reflect the contradiction appropriately

## Scenario C — Competitor-Heavy Campaign

Create a state where:

- the strategy is mostly built from competitor-derived signals

Expected behavior:

- confidence must be reduced
- budget behavior must be conservative

- no aggressive execution path should appear

## Scenario D — Strong / Trusted Campaign

Create a state where:

- signal composition is stronger
- more trusted data exists
- metrics are sufficient

Expected behavior:

- engines should run fully

- dashboard should match actual system strength
