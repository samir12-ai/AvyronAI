# Validation Rules

Use a real production campaign.

Use real competitor data.

Use real Instagram posts.

Use real Instagram comments.

Use real TikTok data where already available.

Do not fabricate audience data.

If an engine requires user-entered business metrics that are intentionally unavailable during validation (for example `primaryKpi` or `dataWindowDays`), inject clearly marked temporary validation values only for this run.

The objective is to validate execution, not business accuracy.

Never persist these temporary values as customer data.
