For each claim:

* compute semantic similarity against all available signals
* assign top matching signal IDs
* allow multiple matches if needed

This can be done via:

* embeddings + cosine similarity
* keyword overlap + scoring
* hybrid matching

After mapping:

* if a claim has **no valid signal match**:

* orphan claims to pass silently

## 4. Recompute Coverage Internally

Signal coverage must be:

> **system-calculated**, not model-reported

(# claims with valid signal mapping) / (total claims)

* propose positioning logic

It should NOT:

* perform structured data linkage

* enforce grounding
