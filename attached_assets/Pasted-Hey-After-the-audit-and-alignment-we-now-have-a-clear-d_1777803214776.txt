## 1. Core principle — fully user-controlled system

No action should execute automatically.

- No automatic reruns  
- No automatic DNA mutation  
- No automatic strategy changes  

The system must:

detect → explain → suggest → wait for user action

All execution must be triggered by explicit user interaction (buttons / CTAs).

---

## 2. Q2 SHIFTED — actionable alert (not passive)

When Q2 = SHIFTED:

We need a strong, actionable dashboard alert (not just a badge).

### Required behavior:

- Show a top-level alert  
- Explain that the market has shifted and current analysis may be outdated  
- Add a CTA button:

Run New Analysis

### Button behavior:

- Calls backend endpoint  
- Runs a new pipeline analysis using fresh data  
- Does NOT mutate DNA  
- Does NOT auto-apply strategy changes  

Flow:

Q2 SHIFTED  
→ alert  
→ user clicks CTA  
→ new analysis runs  
→ results displayed with lineage

## 4. Strategy maturity / learning window (critical)

Do NOT allow premature judgment of strategies.

Before Q1 produces a strong verdict, add a maturity gate.

The system must evaluate:

- DNA age  
- strategy type (organic / paid / hybrid)  
- exposure volume  
- rhythm compliance  
- early traction signals  

### Rules:

- Do NOT mark strategy as DEGRADED in first 1–2 weeks without sufficient data  
- Organic strategies require longer windows  
- Paid strategies can be evaluated faster  
- If execution is low → do NOT blame DNA  

### Add interpretation states:

- TOO_EARLY_TO_JUDGE  
- GAINING_TRACTION  
- EXECUTION_TOO_LOW  
- NEEDS_MORE_EXPOSURE  

These appear in dashboard + explanation layer.
