🔧 Required Tasks

1. Add campaign_id to strategy_decisions (CRITICAL)

Current issue:
	•	strategy_decisions is only scoped by account_id
	•	this creates a risk of cross-campaign influence within the same account

Required:
	•	add campaign_id column to strategy_decisions
	•	backfill existing records where possible
	•	enforce campaign scoping in:
	•	decision creation
	•	plan synthesis
	•	outcome tracking
	•	any read paths using decisions

Goal:
👉 decisions must be fully isolated per campaign, not just per account

⸻

2. Filter Synthetic Comments in Shared Pool Reuse

Current issue:
	•	shared profile reuse may copy isSynthetic = true comments across accounts

Required:
	•	update reuse query to include:
	•	isSynthetic = false
	•	ensure only real scraped comments are reused

Goal:
👉 prevent future cross-account contamination from generated data

⸻

3. Concurrency & Queue Hardening

Current issue:
	•	global concurrency is limited (3 jobs)
	•	queue expiry is 10 minutes
	•	system will break under moderate scale

Required:
	•	review and increase:
	•	global concurrent job limit
	•	per-account concurrency (if safe)
	•	revisit queue expiry logic (10-minute wall)
	•	ensure jobs do not silently fail due to queue timeout

Goal:
👉 system must handle >30 campaigns without dropping jobs

⸻

4. Cleanup Legacy “Unscoped” Memory Entries

Current issue:

Required:

Goal:
👉 eliminate inconsistent or legacy state before scaling
