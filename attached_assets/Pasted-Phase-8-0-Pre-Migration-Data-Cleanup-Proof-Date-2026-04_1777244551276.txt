6. What changed in the source code (delta from previous bundle)
Two files were patched to enforce self-cleanup discipline. Both fixes are PURE bug fixes — they do not change harness assertions, scenarios, or pass/fail criteria.

server/pipeline/integrity-harness.ts
Added imports: pipelineDna, pipelineDnaVersions, eq, inArray.
Replaced the broken legacy-table cleanup (lines 404–405) with proper Drizzle deletes against pipeline_dna + pipeline_dna_versions scoped by accountId = HARNESS_ACCT_A.
Removed the silent .catch(() => {}) swallow — if cleanup fails now it surfaces.
server/pipeline/e2e-system-test.ts
Added sql to the drizzle-orm import.
Added new function sweepE2EResidue() that collects every campaign_id LIKE 'e2e-%' from 9 source tables and calls the existing per-campaign cleanup() for each.
Wrapped main() body in try/finally so the sweep runs even if a scenario throws. Moved process.exit after the finally block so the cleanup completes before the process terminates.
Both fixes are now in the rebuilt bundle. Main will inherit them when it receives the bundle.
