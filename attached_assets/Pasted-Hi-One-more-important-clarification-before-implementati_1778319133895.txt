## 4) Prevent Field Misplacement

The Channel issue happened because:

* engine emitted:

  * `funnelReconstruction.funnelStages`
* consumer expected:

  * `output.funnelStages`

This must never happen again.

Required:

* no manual downstream field reads
* all field resolution through contract helper
* shared aliases / legacy paths only if explicitly declared
* all consumers use the same canonical contract path

Example:

```ts
requireContractField("channel_selection", "funnelStages")
```

not:

```ts
output?.funnelStages
```
