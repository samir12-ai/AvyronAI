🔴 1. Agent Box — Preserve Insights (Critical)

Current Issue
	•	When the user interacts with the agent (chat), the proactive insights disappear.
	•	This makes the system feel inconsistent and “stateless”.

Required Change

We need to separate system insights from chat messages:

Structure:
	•	System Insights (persistent, top section)
	•	Chat (interactive, below)

Behavior:
	•	Insights are loaded from strategy_decisions
	•	They persist across:
	•	user messages
	•	navigation
	•	refresh
	•	They are only updated by the worker (not overwritten by chat)

Goal:

Insights = system state
Chat = interaction layer

🔴 2. Intelligence Enforcement Layer (Critical)

Current Issue
	•	The agent does not consistently follow reasoning standards
	•	It produces weak / generic insights in some cases

Required Change

We need to enforce insight quality at the system level (not rely on prompts)

⸻

Insight Schema (mandatory)

All insights must follow:
	•	observation (what happened)
	•	reason (why it happened)
	•	evidence (data / comparison)
	•	action (specific system action)
	•	confidence (0–1)

⸻

Enforcement Logic

Before displaying any insight:
	•	If any field is missing → reject or regenerate
	•	No free-form responses allowed

⸻

Optional (if simple)
	•	Add post-processing validation or retry generation if schema is incomplete

⸻

Goal

Ensure every insight is:
	•	actionable
	•	data-backed
	•	consistent in structure

⸻
