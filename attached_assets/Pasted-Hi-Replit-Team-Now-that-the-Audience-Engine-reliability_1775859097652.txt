## 3. Audience Engine Logic Changes (Before or Alongside Ingestion)

The current engine is now reliable, but these new sources will only be useful if the engine can distinguish them correctly.

We want to support:

### A. Source typing

Every matched signal should know whether it came from:

* comments
* captions
* website
* blog
* TikTok
* reviews

### B. Source-aware weighting

We want weighting to reflect signal quality, for example:

* reviews > comments > TikTok > captions

### C. Cross-source agreement

If the same signal appears across multiple source types, confidence should increase.

Please confirm:

* whether the current `matchPatternClusters()` + confidence pipeline can support this cleanly
* and where you would extend it
