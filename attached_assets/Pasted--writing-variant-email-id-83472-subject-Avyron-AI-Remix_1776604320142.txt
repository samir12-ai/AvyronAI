🔴 Core Objective (Phase 1)

Build a clean, deterministic, and validated data pipeline where:
	•	Data flows correctly end-to-end without corruption
	•	Every object is traceable (no anonymous data)
	•	No runtime inconsistencies
	•	No mixing of user vs competitor data
	•	No analysis runs on outdated or partial data

We are NOT optimizing intelligence yet.
We are building the foundation layer only.

⸻

⚠️ Critical Non-Negotiable Rules

These are HARD constraints:
	1.	NO runtime mismatch
	•	No agent or process should run on outdated runtime context
	•	Every run must be isolated and clearly identified
	2.	NO processing on stale data
	•	Never analyze old snapshots as if they are new
	•	All analysis must explicitly reference its snapshot + time window
	3.	NO data without identity
Every object MUST include:
	•	run_id
	•	snapshot_id
	•	entity_id
	•	lane (user / competitor / bridge / shared)
	•	schema_version
	4.	NO direct raw data usage
	•	Raw data must be normalized → snapshotted → then analyzed
	5.	NO cross-lane contamination
	•	Competitor data must NEVER affect user truth directly
	•	Only structured signals pass through the bridge
	6.	NO silent failures or hidden mutations
	•	Everything must be validated and traceable
	7.	STRICT validation required
	•	Data acceptance must be hard, not permissive
	•	Reject incomplete or inconsistent data

⸻

🧠 System Architecture Overview

1. Shared Layer
	•	Data Collector (scraping only)
	•	Normalization Layer
	•	Snapshot Builder
	•	Validation Layer
	•	Control Layer

2. User Lane
	•	User Snapshot Agent
	•	User Signal Agent
	•	Manual Input (weekly truth)
	•	DNA Hypothesis Agent
	•	Cluster Assignment Agent
	•	Weekly Outcome Evaluator

3. Competitor Lane
	•	Competitor Snapshot Agent
	•	Competitor Signal Agent
	•	Market Intelligence Adapter (competitor-only mode)
	•	Competitor Change Detection

4. Bridge Layer
	•	Signal Translation
	•	Relevance Mapping (NO raw data transfer)

5. Governance
	•	Boss Agent (orchestrator only)
	•	Dashboard Output Layer

🔁 Pipeline Flow (Simplified)

User Side (every ~6 hours)
	1.	Create run
	2.	Scrape user data
	3.	Normalize
	4.	Create snapshot
	5.	Validate snapshot
	6.	Extract signals
	7.	Store outputs

⸻

Competitor Side (every ~48 hours)
	1.	Create run
	2.	Scrape competitor data
	3.	Normalize
	4.	Create snapshot
	5.	Run competitor-only analysis (isolated)
	6.	Extract signals
	7.	Detect changes vs previous snapshot
	8.	Generate change events
	9.	Pass structured signals through bridge

⸻

Weekly Layer
	1.	Accept manual input (leads, qualified, calls, etc.)
	2.	Link to content clusters
	3.	Evaluate DNA performance
	4.	Output structured recommendations
